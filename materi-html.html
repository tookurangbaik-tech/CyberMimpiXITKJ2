🌐 Modul 1: Struktur Dasar HTML

1. Analogi & Konsep Dasar

HTML (HyperText Markup Language) bukanlah bahasa pemrogram berlogika seperti Python atau C++, melainkan Bahasa Penanda (Markup Language).

💡 Analogi Bangunan: Jika situs web adalah sebuah rumah, HTML adalah fondasi, tiang beton, batu bata, dan pintunya. CSS adalah cat dan interiornya, sedangkan JavaScript adalah sistem kelistrikan dan saklar otomatisnya.

2. Anatomi Elemen HTML

Sebagian besar elemen HTML dibangun oleh 3 bagian utama:

  • Tag Pembuka (Opening Tag): Menandai awal elemen, contoh <p>.
  • Isi Konten (Content): Teks atau media yang ingin ditampilkan.
  • Tag Penutup (Closing Tag): Menandai akhir elemen, ditandai garis miring, contoh </p>.
  • Atribut: Informasi tambahan dalam tag pembuka, contoh id="utama" atau class="judul".

3. Penjelasan Struktur Utama

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Halaman Pertamaku</title> </head> <body> <h1>Halo Dunia!</h1> <p>Ini adalah konten utama web saya.</p> </body> </html>
  • <!DOCTYPE html>: Deklarasi wajib di baris pertama untuk memberi tahu browser bahwa dokumen ini menggunakan standar versi HTML5 modern.
  • <html lang="id">: Pembungkus seluruh kode HTML. Atribut lang="id" membantu Google menyadari bahwa isi web berbasa Indonesia.
  • <head>: Wadah informasi "di balik layar" (Metadata). Konten di sini tidak langsung muncul secara visual di layar web.
  • <meta charset="UTF-8">: Memastikan semua simbol dan karakter bahasa dapat dibaca tanpa error huruf aneh.
  • <meta name="viewport"...>: Sangat penting! Mengatur agar tampilan web otomatis responsif saat dibuka dari HP/Smartphone.
  • <title>: Menentukan nama yang muncul di tab paling atas browser.
  • <body>: Area utama tempat semua teks, gambar, video, dan tombol ditampilkan ke pengguna.
💡 Tips Best Practice: Selalu gunakan huruf kecil (lowercase) untuk penulisan nama tag, contoh: gunakan <p> bukan <P>.
⚠️ Kesalahan Pemula: Lupa menutup tag! Jika tag pembuka tidak ditutup, elemen di bawahnya akan ikut berantakan.

📝 Modul 2: Format Teks & Paragraf

1. Tag Heading (Judul Utama & Sub-Judul)

HTML menyediakan 6 tingkatan judul dari <h1> hingga <h6>.

💡 Analogi Surat Kabar: <h1> adalah Berita Utama di sampul paling depan, <h2> adalah Sub-Bab, dan seterusnya. Berita utama (h1) idealnya hanya ada 1 dalam satu halaman web agar Google mudah mengenali topik utama web Anda.

<h1>Judul Utama (Paling Besar & Penting)</h1> <h2>Sub-Judul Bagian Utama</h2> <h3>Sub-Sub Judul</h3> <!-- h4, h5, h6 semakin kecil secara hierarki -->

2. Paragraf & Pemisah Baris

  • <p>: Menyusun teks menjadi satu paragraf utuh dan memberikan jarak margin otomatis di atas & bawahnya.
  • <br>: Single Line Break (Garis Baru). Tag ini merupakan Void Tag (tidak butuh tag penutup </br>). Gunakan jika ingin membuat baris baru di dalam paragraf tanpa membuat paragraf baru.
  • <hr>: Horizontal Rule. Membuat garis lurus pembatas antar paragraf/topik.

3. Pemformatan Penekanan Teks

  • <strong> atau <b>: Mencetak tebal teks. (Gunakan strong untuk teks yang secara makna penting).
  • <em> atau <i>: Mencetak miring teks. (Gunakan em untuk penekanan penuturan istilah).
  • <u>: Memberi garis bawah pada teks.
  • <mark>: Memberi efek stabilo/highlight warna kuning pada teks.
  • <small>: Memperkecil ukuran teks (biasanya untuk catatan kaki/copyright).
  • <sub> & <sup>: Teks subscript (bawah: H2O) & superscript (atas: 102).
<p>Air memiliki rumus kimia H<sub>2</sub>O dan membutuhkan suhu <mark>100&deg;C</mark> untuk mendidih. <br>Pengingat: Jangan lupa <strong>matikan kompor</strong>!</p>
⚠️ Kesalahan Pemula: Menggunakan <br> berkali-kali hanya untuk memberi jarak antar elemen. Gunakan margin CSS untuk mengatur jarak, bukan tag <br> berlebihan.

🔗 Modul 3: Hyperlink (Navigasi Web)

1. Analogi & Konsep

Hyperlink adalah jembatan yang menghubungkan satu dokumen HTML ke dokumen lainnya di seluruh dunia. Tanpa link, World Wide Web (WWW) tidak akan pernah ada.

Elemen utama pembuat tautan adalah tag anchor <a>.

2. Anatomi Tag & Atribut Penting

<a href="https://google.com" target="_blank" title="Buka Google">Klik Di Sini Ke Google</a>
  • href (Hypertext Reference): Atribut paling **wajib**. Berisi alamat lokasi tujuan link. Tanpa atribut ini, tag <a> tidak dapat diklik.
  • target="_blank": Mengatur agar alamat tujuan terbuka di **Tab Baru** browser, sehingga pengunjung tidak meninggalkan halaman web Anda secara tidak sengaja.
  • target="_self": Opsi standar, membuka link di halaman/tab yang sedang aktif saat ini.
  • title: Teks kecil yang muncul saat kursor mouse diarah/di-hover di atas link.

3. Jenis-jenis URL

  • URL Absolut: Mengarahkan ke domain luar lengkap beserta protocol-nya, contoh: href="https://facebook.com".
  • URL Relatif: Mengarahkan ke file di dalam folder komputer yang sama, contoh: href="kontak.html" atau href="folder/tentang.html".
  • Anchor Link (Internal Halaman): Meloncat langsung ke bagian spesifik di halaman yang sama menggunakan ID, contoh: href="#bagian3".
  • Mailto & Tel Link: Membuka aplikasi Email / Telepon otomatis, contoh: href="mailto:admin@sekolah.sch.id".
💡 Tips Praktis: Jangan menuliskan kata link dengan kalimat "Klik Disini". Tulislah teks anchor secara informatif, misalnya: <a href="materi.pdf">Unduh Modul PDF HTML</a>.

🖼️ Modul 4: Media (Gambar, Audio, Video)

1. Tag Gambar (<img>)

Tag <img> adalah *Void Tag* (tidak punya tag penutup). Gambar dimuat dari file eksternal.

<img src="pemandangan.jpg" alt="Pemandangan gunung saat matahari terbit" width="400" height="250">
  • src (Source): Alamat path atau URL dari gambar yang ingin ditampilkan.
  • alt (Alternate Text): **Sangat Penting!** Teks deskripsi alternatif yang akan tampil jika sinyal internet buruk dan gambar gagal dimuat. Selain itu, membantu tunanetra (Screen Reader) dan SEO Google.
  • width & height: Menentukan ukuran lebar dan tinggi gambar (dalam satuan piksel).

2. Tag Audio (<audio>)

Memutar musik atau rekaman suara langsung di web tanpa plugin eksternal.

<audio controls autoplay> <source src="musik.mp3" type="audio/mpeg"> Browser Anda tidak mendukung pemutar audio. </audio>
  • controls: Menampilkan tombol play, pause, serta pengatur volume.

3. Tag Video (<video>)

<video width="500" controls poster="sampul.jpg"> <source src="tutorial.mp4" type="video/mp4"> Browser Anda tidak mendukung pemutar video. </video>
⚠️ Kesalahan Pemula: Mengabaikan atribut alt pada gambar. Pastikan atribut alt selalu terisi deskripsi relevan!

📋 Modul 5: Daftar / List

1. Analogi & Fungsi

List digunakan untuk mengelompokkan sekumpulan item terkait. Contohnya daftar menu navigasi, resep makanan, atau urutan langkah-langkah kerja.

2. Jenis-jenis List HTML

  1. Unordered List (<ul>): Daftar yang **tidak mementingkan urutan**. Ditandai dengan poin simbol bulat/bullet.
  2. Ordered List (<ol>): Daftar yang **mementingkan urutan prosedural**. Ditandai dengan angka (1,2,3) atau huruf (A,B,C).
  3. List Item (<li>): Tag wajib untuk membungkus setiap poin di dalam tag <ul> maupun <ol>.
<!-- Unordered List --> <ul> <li>Buku Tulis</li> <li>Pensil 2B</li> </ul> <!-- Ordered List dengan atribut tipe huruf A, B, C --> <ol type="A" start="1"> <li>Langkah Pertama: Buka browser</li> <li>Langkah Kedua: Masukkan alamat URL</li> </ol>

3. List Bersarang (Nested List)

Anda dapat memasukkan list baru di dalam sebuah tag <li> untuk membuat struktur sub-kategori.

<ul> <li>Buah-buahan: <ul> <li>Apel</li> <li>Mangga</li> </ul> </li> </ul>

📊 Modul 6: Tabel Data Terstruktur

1. Konsep Dasar

Tabel digunakan untuk menampilkan data 2 dimensi yang terdiri dari baris (horizontal) dan kolom (vertikal), seperti jadwal pelajaran atau daftar harga produk.

2. Tag Penyusun Tabel

  • <table>: Pembungkus utama seluruh tabel.
  • <tr> (Table Row): Menandai baris horizontal baru.
  • <th> (Table Header): Sel khusus judul kolom. Teks otomatis dibuat tebal dan rata tengah.
  • <td> (Table Data): Sel penampung isi data biasa.

3. Menggabungkan Sel (Colspan & Rowspan)

  • colspan="2": Menggabungkan beberapa **kolom** menjadi satu sel horizontal (melebar ke samping).
  • rowspan="2": Menggabungkan beberapa **baris** menjadi satu sel vertikal (memanjang ke bawah).
<table border="1" style="width:100%"> <thead> <tr> <th>No</th> <th>Nama Siswa</th> <th>Nilai</th> </tr> </thead> <tbody> <tr> <td>1</td> <td>Budi Santoso</td> <td>90</td> </tr> </tbody> </table>

📥 Modul 7: Formulir Interaktif

1. Fungsi Formulir

Formulir adalah sarana interaksi utama agar pengunjung web dapat memasukkan data (seperti formulir pendaftaran, kolom komentar, atau halaman login) untuk dikirimkan ke server.

2. Tag Utama & Atribut

<form action="proses.php" method="POST">
  • action: Menentukan alamat URL script pemroses data saat formulir dikirim.
  • method="GET": Mengirim data dengan menampilkannya pada URL bar browser (kurang aman untuk password).
  • method="POST": Mengirim data secara rahasia di balik layar (Sangat cocok untuk data rahasia/login).

3. Elemen Elemen Input

<!-- Label terhubung ke ID input --> <label for="emailUser">Alamat Email:</label> <input type="email" id="emailUser" name="email" placeholder="contoh@gmail.com" required> <!-- Password --> <input type="password" name="sandi" placeholder="Masukkan kata sandi"> <!-- Pilihan Radio (Pilih salah satu) --> <input type="radio" id="pria" name="gender" value="L"> <label for="pria">Laki-laki</label> <!-- Checkbox (Dapat memilih lebih dari satu) --> <input type="checkbox" id="hobi1" name="hobi" value="coding"> <label for="hobi1">Suka Coding</label> <!-- Dropdown Select --> <select name="kota"> <option value="jkt">Jakarta</option> <option value="bdg">Bandung</option> </select> <!-- Textarea (Komentar Panjang) --> <textarea name="pesan" rows="4" placeholder="Ketik pesan..."></textarea> <button type="submit">Kirim Data</button>
💡 Atribut Penting Input: Atribut placeholder memberikan teks petunjuk transparan di dalam kolom sebelum diisi. Atribut required memaksa isian wajib diisi pengguna.

📦 Modul 8: Container & HTML5 Semantic Tag

1. Perbedaan Block-Level vs Inline Element

Elemen dalam HTML secara alami terbagi menjadi 2 tipe perilaku layout:

  • Block-Level Element: Selalu memulai di **baris baru** dan lebarnya secara otomatis memenuhi 100% lebar layar halaman. Contoh: <div>, <p>, <h1>-<h6>, <ul>.
  • Inline Element: Tidak membuat baris baru. Lebarnya **hanya sebesar konten di dalamnya**. Contoh: <span>, <a>, <b>, <img>.

2. Tag Container Utama

  • <div> (Division): Wadah pembungkus generik bertipe **Block**. Sangat sering digunakan untuk mengelompokkan beberapa tag menjadi satu seksi tatanan layout.
  • <span>: Wadah generik bertipe **Inline**. Biasanya digunakan untuk membungkus beberapa kata spesifik di dalam paragraf untuk diberi warna CSS berbeda.

3. Tag Semantik Modern HTML5

Daripada menggunakan tag <div> secara berlebihan untuk semua hal, HTML5 menyediakan tag yang bermakna spesifik (Semantic):

  • <header>: Bagian atas web (logo, judul utama).
  • <nav>: Wadah kelompok menu navigasi utama.
  • <main>: Konten inti yang paling unik di halaman web.
  • <section>: Kelompok atau bab pembahasan konten.
  • <article>: Konten mandiri seperti postingan blog/berita.
  • <footer>: Bagian paling bawah web (copyright, kontak).
