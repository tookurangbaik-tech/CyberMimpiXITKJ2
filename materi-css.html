🎯 Materi: Selektor & Sintaks CSS (Ilmu Pilih-Memilih)

Pengertian Dasar: HTML itu ibarat kerangka tubuh manusia (tulang doang tanpa baju), sedangkan CSS (Cascading Style Sheets) adalah pakaian, jaket, dan makeup-nya agar keliatan ganteng/cantik.

💡 Fakta Unik: Kata "Cascading" artinya berjenjang atau menular. Mirip kayak gosip di kelas XI TKJ—kalau pusatnya nyebar, semuanya ikutan kena!

Anatomi Penulisan CSS (Sintaks):

  • selektor { properti: nilai; }
  • Contoh nyata: h1 { color: blue; }
  • Selektor: Menunjuk elemen mana yang mau diubah (misal: h1).
  • Properti: Bagian apa yang mau diubah (misal: color / warna).
  • Nilai (Value): Mau diubah jadi seperti apa (misal: blue / biru).

3 Jenis Selektor Paling Sakti:

  • Tag Selector: Menyerang seluruh tag yang sama sekaligus (contoh: p { ... } bikin semua paragraf berubah).
  • Class Selector (Pakai titik .): Penanda fleksibel. Bisa dipasang ke banyak elemen berbeda (contoh: .kartu-keren).
  • ID Selector (Pakai pagar #): Sifatnya egois dan unik. Hanya boleh dipakai oleh 1 elemen spesifik per halaman (contoh: #header-utama).

⚠️ Catatan Kematian: Jangan pernah lupa nulis titik koma ; di akhir baris properti. Kalau lupa, web kamu bakal ngambek massal nggak mau berubah gayanya!

🎨 Materi: Warna & Background (Biar Nggak Monoton)

Pengertian: Kalau web isinya cuma tulisan hitam di atas latar putih polos dari tahun 1990-an, dijamin pengunjungnya langsung kabur karena dikira web horor.

Properti Utama Pewarnaan:

  • color: Digunakan khusus untuk mewarnai teks/huruf. (Bukan mewarnai latar belakang ya, awas kebalik!).
  • background-color: Digunakan untuk mewarnai latar belakang suatu kotak atau elemen.

3 Cara Menulis Warna di CSS:

  • Nama Warna Langsung: red, blue, cyan, crimson, dll. (Gampang, tapi pilihannya terbatas).
  • Kode Hexadecimal (Hex): Awalan tanda pagar diikuti 6 karakter, contoh #ff0000 (merah pekat), #00ff00 (hijau), #1d5f91 (biru cyber).
  • Format RGB (Red, Green, Blue): Mengatur takaran cahaya angka dari 0 sampai 255, contoh rgb(29, 95, 145).
💡 Tips Estetik: Hindari pakai warna hijau neon terang menyilaukan kalau nggak mau teman sekelas kamu mendadak buta massal di ruang lab komputer!

✍️ Materi: Teks & Tipografi (Font Styling)

Pengertian: Mengatur tulisan agar enak dipandang mata. Huruf yang berantakan bikin web kelihatan kayak surat kaleng.

Properti Wajib Hafal:

  • font-size: Mengatur ukuran huruf. Bisa pakai satuan piksel (16px), rem (1.5rem), atau persen (120%).
  • font-family: Mengatur jenis huruf (font). Contoh: Arial, sans-serif atau Courier New, monospace.
  • font-weight: Mengatur ketebalan huruf. Nilainya bisa bold, normal, atau angka ketebalan seperti 400 dan 700.
  • text-align: Mengatur posisi perataan teks. Pilihannya: left (kiri), center (tengah), right (kanan), atau justify (rata kiri-kanan ala proposal sekolah).
  • text-decoration: Untuk ngasih garis bawah (underline), coret tengah (line-through), atau menghilangkan garis bawah bawaan link (none).

📦 Materi: Box Model (Padding vs Margin)

Pengertian Konsep: Di dalam dunia CSS, semua elemen dianggap sebagai kotak (box). Masalah paling klasik umat manusia belajar koding adalah sering tertukar antara Padding dan Margin.

🧠 Analogi Gampang (Paling Masuk Akal):
  • Padding: Jarak ruang di dalam kotak. Ibarat jarak antara barang belanjaan di dalam kardus dengan dinding kardus itu sendiri.
  • Margin: Jarak ruang di luar kotak. Ibarat jarak antar kardus belanjaan yang kamu letakkan berdampingan di lantai supaya nggak saling dempetan.

Urutan Penulisan Arah Jam (Atas, Kanan, Bawah, Kiri):

  • Contoh: margin: 10px 20px 10px 20px; (Atas 10px, Kanan 20px, Bawah 10px, Kiri 20px).
  • Atau cukup margin: 15px auto; biar otomatis berada di tengah halaman!

🔲 Materi: Border & Border-Radius (Seni Kotak Melengkung)

Pengertian: Kalau kotak web kamu kelihatan kaku bersudut tajam 90 derajat, kita bisa kasih bingkai (border) dan melengkungkan sudutnya pakai trik sihir CSS.

Properti Border:

  • border: Menggabungkan ketebalan, jenis garis, dan warna sekaligus dalam satu baris.
  • Contoh: border: 2px solid black; (Tebal garis 2px, garis lurus solid, warna hitam). Jenis garis lain ada dashed (putus-putus) dan dotted (titik-titik).

Properti Border-Radius:

  • border-radius: Mengubah sudut kotak yang tadinya lancip jadi tumpul melengkung.
  • Contoh: border-radius: 12px; bikin sudutnya halus estetik ala tombol aplikasi modern.
  • Kalau nilainya dibikin 50%, kotak persegi bakal berubah sulap jadi lingkaran bulat sempurna! Keren kan? ✨

📐 Materi: Flexbox Layout (Penyelamat Stres Koding)

Pengertian: Dulu sebelum ada Flexbox, mengatur posisi elemen agar sejajar ke samping atau berada persis di tengah layar adalah ujian kesucian tingkat dewa yang bikin frustrasi.

Cara Kerja Utama Flexbox:

  • display: flex; : Senjata utama yang wajib dipasang di kotak pembungkus (parent). Sekali diketik, anak-anak di dalamnya langsung patuh berbaris rapi secara horizontal!
  • justify-content : Mengatur pergerakan posisi item secara horizontal (mendatar). Nilainya bisa center (di tengah), space-between (jarak merata mentok pinggir), atau space-around.
  • align-items : Mengatur pergerakan posisi item secara vertikal (tegak lurus). Sangat ampuh buat bikin elemen pas di tengah secara vertikal tanpa bikin emosi.
🔥 Kesimpulan: Menguasai Flexbox artinya kamu sudah melewati 50% rintangan terbesar menjadi web developer sejati!
