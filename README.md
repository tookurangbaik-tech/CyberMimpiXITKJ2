CyberMimpi • Portal & Ruang Digital XI TKJ 2
​Portal informasi, direktori ID Card interaktif, kuis edukasi, dan ruang digital kebanggaan kelas XI TKJ 2 SMKN 8 Garut. Dibuat murni tanpa framework, hasil kreativitas anak TKJ!
​Fitur Unggulan:
​Hero Section Animasi Vector: Tampilan pembuka interaktif dengan efek pemandangan, matahari bersinar, dan teks bergulir dinamis.
​ID Card Anggota Kelas Interaktif: Kartu identitas unik untuk setiap anggota kelas (lengkap dengan wali kelas dan pengurus) dengan tema warna-warni yang estetik.
​Pemutar Musik Kustom: Setiap kartu profil memiliki audio player mini yang dapat memutar lagu atau suara khas masing-masing anggota.
​Fitur Pencarian Kilat: Memudahkan pengunjung mencari nama teman atau jabatan di kelas dalam hitungan detik.
​Asisten Virtual Chibi Elaina: Widget asisten interaktif di pojok kanan bawah yang menyapa pengunjung dengan candaan santai khas anak sekolah.
​Navigasi Edukatif: Menu lengkap untuk Beranda, Card Anggota, Jadwal Pelajaran, hingga Modul Belajar.
​Teknologi yang Digunakan:
Proyek ini dibangun menggunakan teknologi dasar tanpa ketergantungan framework berat:
​HTML5 untuk struktur halaman web.
​CSS3 untuk desain antarmuka modern (Glassmorphism, Bento Grid, responsive layout).
​JavaScript (Vanilla) untuk logika interaktif popup, audio player, dan filter pencarian.
​FontAwesome & Google Fonts untuk ikon dan tipografi.
​Cara Menjalankan Proyek (Local Setup):
​Clone repository: git clone https://github.com/tookurangbaik-tech/cybermimpi.git
​Masuk ke direktori: cd cybermimpi
​Buka file index.html atau Wawa.html langsung di browser.
